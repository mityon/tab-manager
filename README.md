# Tab Manger

開いているChromeのタブを検索・整理する拡張機能です。ツールバーのアイコンからポップアップを開いて使います。

## できること

- 「このウィンドウ」と「すべてのウィンドウ」を切り替えてタブを表示
- タイトルまたはURLでタブを検索
- タブをホスト名ごとに表示し、件数を確認してまとめて閉じる
- タブをクリックして移動する、または個別に閉じる
- 同じURLの重複タブを整理。固定タブは閉じず、固定タブがない場合は選択中のタブを優先して残す
- 個別削除・ドメイン一括削除・重複タブ整理の確認ダイアログを設定画面で切り替える

ドメイン一括削除と重複タブ整理は、選択したウィンドウの範囲と検索結果に含まれるタブだけが対象です。ドメインはホスト名の完全一致で判定するため、`example.com` と `www.example.com` は別のグループになります。`chrome://` などのタブは「その他のタブ」に表示されます。

## Chromeで使う

1. 依存関係をインストールします。

   ```sh
   yarn install
   ```

2. ポップアップを静的ファイルとして書き出します。

   ```sh
   yarn export
   ```

3. Chromeの `chrome://extensions` を開き、「デベロッパー モード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」で、このリポジトリの `extensions/` ディレクトリを選択します。

コードを変更した後は `yarn export` を再実行し、`chrome://extensions` で拡張機能を再読み込みしてください。`extensions/dist/` は生成物です。

## 使い方

ポップアップ上部で対象ウィンドウを選び、必要ならタイトルやURLで検索します。タブ名を押すとそのタブに移動し、右端の閉じるアイコンで個別に閉じられます。ドメイン名の横にあるゴミ箱アイコンは、そのグループの表示中のタブをまとめて閉じます。「重複タブを整理」は表示中の同じURLのタブを整理します。

右上の設定アイコンから、削除前の確認ダイアログを操作ごとに設定できます。初期状態では個別削除はオフ、ドメイン一括削除と重複タブ整理はオンです。設定はChromeのローカルストレージに保存されます。

## 開発

| コマンド | 内容 |
| --- | --- |
| `yarn dev` | `http://localhost:3000` で画面を確認する。タブ操作には拡張機能としての実行環境が必要 |
| `yarn lint` | ESLintを実行する |
| `yarn build` | Next.jsの本番ビルドを作る |
| `yarn export` | `extensions/dist/` にポップアップを書き出す |

Next.js 13、TypeScript、Tailwind CSS、Chrome拡張機能 Manifest V3を使用しています。拡張機能はタブ操作用の `tabs` 権限と、確認設定の保存用の `storage` 権限を使います。
